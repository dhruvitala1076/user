# Fitness Website

## 📌 Project Overview

This is a dynamic fitness website designed to help users manage their fitness journey. The website provides features such as user registration, login, membership plans, personalized diet and exercise plans, progress tracking, and profile management.

## 👤 My Role

I worked as a **User-side developer/tester** in this project. I worked with and tested the user functionalities of the website, including:

* User Registration & Login
* User Profile Management
* Membership Selection
* Personalized Diet Plan
* Exercise Plan
* Progress Tracking
* User Dashboard
* Change Password

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* jQuery
* PHP
* MySQL

## 🎯 Project Objective

The main objective of this project is to provide users with an easy-to-use platform for managing their fitness activities, memberships, diet plans, exercise routines, and progress.

## ✨ Key Features

* Secure User Login & Registration
* User Dashboard
* Membership Plans
* Personalized Diet & Exercise
* Fitness Progress Tracking
* Profile Management
* Password Management

## 📚 Learning Outcome

Through this project, I gained practical experience in web development, database connectivity, user-side functionality, form validation, and working with PHP and MySQL.
